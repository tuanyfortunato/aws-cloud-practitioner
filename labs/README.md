# Labs Práticos

Registre aqui os exercícios práticos feitos no console. Um arquivo por lab
(ex.: `01-criar-bucket-s3.md`).

> ⚠️ **Cuidado com custos:** use o Free Tier, configure um **AWS Budget** com alerta
> antes de começar e **apague os recursos** ao terminar cada lab.
> Nunca faça commit de chaves de acesso, senhas ou IDs de conta.
