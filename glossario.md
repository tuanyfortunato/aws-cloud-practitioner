# Glossário

Termos em ordem alfabética.

| Termo | Significado |
|---|---|
| AZ (Availability Zone) | Um ou mais data centers isolados dentro de uma Região |
| CAPEX | Despesa de capital — investimento antecipado em infraestrutura |
| Edge Location | Ponto de presença usado pelo CloudFront e Route 53 para baixa latência |
| Elasticidade | Capacidade de aumentar e reduzir recursos automaticamente conforme a demanda |
| OPEX | Despesa operacional — paga conforme o uso |
| Região | Área geográfica com várias AZs |
| Serverless | Modelo em que você não gerencia servidores (ex.: Lambda) |
|  |  |
