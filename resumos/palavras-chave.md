# Palavras-chave → Serviço

| Se a questão fala em... | Pense em... |
|---|---|
| Auditoria de chamadas de API / "quem fez" | AWS CloudTrail |
| Relatórios de conformidade | AWS Artifact |
| Recomendações de custo, segurança e limites | AWS Trusted Advisor |
| Dados sensíveis (PII) no S3 | Amazon Macie |
| Executar código sem servidor | AWS Lambda |
| Infraestrutura como código | AWS CloudFormation |
| Estimar custo antes de criar recursos | AWS Pricing Calculator |
| Conexão dedicada e privada com a AWS | AWS Direct Connect |
| Migrar petabytes de dados offline | AWS Snowball |
| Baixa latência para conteúdo global (CDN) | Amazon CloudFront |
|  |  |
