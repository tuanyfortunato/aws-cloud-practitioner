# Amazon S3 (Simple Storage Service)

> **Categoria:** Armazenamento de objetos · **Domínio:** 2 (segurança/criptografia) e 3 · **Escopo:** Regional (nome do bucket é global) · **Tópico do guia:** [3.8 Amazon S3](../../docs/03-tecnologia-e-servicos/08-s3.md)
>
> **Em uma frase:** armazenamento de objetos ilimitado, com 11 noves de durabilidade, acessado via API/HTTP.

## Para que serve

- Data lakes, backup e arquivamento, mídia, logs, artefatos de build.
- **Hospedagem de site estático** (com CloudFront na frente).
- Origem de conteúdo para CloudFront; destino de CloudTrail, Config, Flow Logs, CUR.

## Conceitos e componentes

| Componente | O que é |
|---|---|
| **Bucket** | Contêiner de objetos. Nome **único globalmente**, mas o bucket fica em **uma região**. |
| **Objeto** | Dados + metadados + chave (o "caminho", ex.: `fotos/2026/a.jpg`). Não há pastas reais, só prefixos. |
| **Classe de armazenamento** | Definida por objeto. Ver [classes do S3](s3-classes-de-armazenamento.md). |
| **Consistência** | **Forte (read-after-write)** para todas as operações. |
| **Tipos de bucket** | *General purpose* (padrão), *directory buckets* (S3 Express One Zone), *table buckets* (S3 Tables/Iceberg) e *vector buckets* (S3 Vectors) — os dois últimos 🧊 fora da prova. |

## Configurações e opções importantes

### Segurança e acesso

| Opção | Detalhe |
|---|---|
| **Block Public Access** | 4 configurações; **ativado por padrão** em buckets novos e pode ser imposto na conta toda. |
| **Bucket policy** | Política baseada em recurso (JSON): quem pode fazer o quê no bucket (inclusive outras contas). |
| **IAM policies** | Permissões das identidades da conta. |
| **ACLs** | Legado. **Object Ownership = "Bucket owner enforced"** (ACLs desativadas) é o padrão. |
| **Presigned URL** | Acesso **temporário** a um objeto privado (download/upload), assinado com credenciais de quem gerou. |
| **Access Points** | Pontos de acesso com políticas próprias para cada aplicação/time. |
| **VPC gateway endpoint** | Acesso privado ao S3 a partir da VPC, gratuito. |
| **OAC (CloudFront)** | Bucket privado servido só via CloudFront. |

### Criptografia

| Opção | Chave | Observação |
|---|---|---|
| **SSE-S3** | Gerenciada pelo S3 (AES-256) | **Padrão para todo objeto novo** |
| **SSE-KMS** | Chave do KMS | Auditoria no CloudTrail, controle por key policy; *S3 Bucket Keys* reduzem custo de chamadas ao KMS |
| **DSSE-KMS** | KMS, duas camadas | Exigências regulatórias específicas |
| **SSE-C** | Fornecida pelo cliente a cada requisição | A AWS não guarda a chave |
| **Client-side** | Cliente criptografa antes de enviar | — |

- Em trânsito: HTTPS (TLS). É possível exigir TLS com condição `aws:SecureTransport` na bucket policy.

### Proteção de dados

| Opção | Detalhe |
|---|---|
| **Versionamento** | Estados: desativado → **ativado** → **suspenso** (nunca volta a "desativado"). Exclusão vira *delete marker*. |
| **MFA Delete** | Exige MFA para apagar versões ou mudar o versionamento; **só o root** ativa (via CLI/API). |
| **Object Lock** | **WORM**. Modos **Governance** (usuários com permissão especial podem remover) e **Compliance** (ninguém, nem o root, apaga até o fim da retenção) + **Legal hold**. Exige versionamento. |
| **Replicação** | **CRR** (entre regiões) e **SRR** (mesma região); exige versionamento nos dois buckets; **S3 RTC** garante 99,99% em 15 min. Não replica objetos já existentes (use Batch Replication). |
| **Lifecycle** | Regras de **transição** (mudar de classe após X dias) e **expiração** (apagar objetos/versões antigas, multipart incompletos). |

### Performance e transferência

| Opção | Detalhe |
|---|---|
| **Multipart upload** | Recomendado acima de 100 MB, **obrigatório acima de 5 GB** (PUT único vai até 5 GB). |
| **Transfer Acceleration** | Upload via edge locations do CloudFront para longas distâncias. |
| **Byte-range fetches** | Download paralelo de partes de um objeto. |
| **Requester Pays** | Quem baixa paga a transferência e as requisições. |

### Outros recursos

- **Event notifications** → Lambda, SQS, SNS ou EventBridge.
- **Static website hosting**: endpoint HTTP do site; documento index e de erro.
- **CORS**, **S3 Inventory**, **Storage Lens** (painel de uso e custo), **Batch Operations**, **S3 Select** (legado), **Object Lambda**.
- **Server access logs** e CloudTrail *data events* para auditoria de leituras/escritas.

## Limites e números

- 📌 Durabilidade **99,999999999% (11 noves)** em todas as classes.
- 📌 Objeto máximo: **5 TB na prova** — 🔄 **50 TB** desde 02/12/2025.
- 📌 PUT único até 5 GB; multipart obrigatório acima disso.
- 🧊 Até 1 milhão de buckets por conta (antes 100 padrão); 3.500 PUT e 5.500 GET por segundo por prefixo.

## Cobrança

- **Armazenamento** (GB-mês, por classe) + **requisições** (PUT, GET…) + **recuperação** (IA/Glacier) + **transferência de saída** + recursos opcionais (replicação, Transfer Acceleration, monitoramento do Intelligent-Tiering, Inventory, Storage Lens avançado).
- Entrada de dados é **grátis**; saída do S3 para o CloudFront é grátis.

## Segurança e responsabilidade compartilhada

- **AWS:** infraestrutura, durabilidade e disponibilidade do armazenamento.
- **Cliente:** **quem acessa** (políticas, Block Public Access), **criptografia** escolhida, versionamento, classificação dos dados (use **Macie** para PII).

## 🔄 Atualizações 2025-2026

- Objeto de até **50 TB** (re:Invent 2025). Na prova, responda **5 TB** se for a única opção.

## ⚠️ Pegadinhas e não confundir

- S3 é **regional**; só o *namespace* de nomes é global.
- **Versionamento** protege contra exclusão acidental; **Object Lock** garante imutabilidade (WORM); **MFA Delete** exige MFA.
- **Presigned URL** (S3) × **signed URL** (CloudFront).
- S3 × EBS × EFS: objeto via API × disco de uma instância × arquivos compartilhados.

## ❓ Perguntas típicas

- "Durabilidade do S3?" → 11 noves.
- "Proteger contra exclusão acidental." → Versionamento (+ MFA Delete).
- "Mover para classes mais baratas após 30 dias." → Lifecycle policy.
- "Acesso temporário a um arquivo privado." → Presigned URL.
- "Copiar objetos para outra região automaticamente." → Cross-Region Replication.
- "Logs não podem ser alterados por 7 anos." → Object Lock (modo Compliance).
- "Acelerar uploads de outros continentes." → Transfer Acceleration.
- "Disparar processamento quando um arquivo chega." → Event notification → Lambda.
- "Acessar o S3 da VPC sem internet." → Gateway VPC endpoint.
