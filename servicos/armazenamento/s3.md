## Que problema resolve

A rede de escolas guarda fotos dos alunos, PDFs de boletins, documentos da matrícula e vídeos de reuniões num servidor de arquivos que enche a cada semestre. Comprar disco, trocar o que quebra e fazer cópias de segurança vira um trabalho sem fim.

O S3 guarda cada arquivo inteiro como um **objeto**, dentro de um **bucket**, e cresce sem que você provisione capacidade. Os dados ficam repetidos em várias zonas de disponibilidade, e a aplicação lê e grava pela rede, por API, console ou CLI. Na escola, as fotos do sistema, os boletins e os backups vão para buckets.

O limite: o S3 não é o disco de uma instância (isso é o [EBS](ebs.md)) nem uma pasta de rede montada por várias máquinas (isso é o [EFS](efs.md)). Ele hospeda sites estáticos, mas não roda código no servidor.

## Como funciona

1. Você cria um **bucket**, escolhendo um nome único e uma Região; os dados ficam nessa Região.
2. Envia os arquivos como **objetos**, cada um identificado por uma **chave** (em `2025/aluno-123.pdf`, a barra é só parte do nome).
3. O bucket nasce privado e criptografado (SSE-S3); o acesso é liberado por políticas do IAM e políticas de bucket.
4. Cada objeto tem uma **classe de armazenamento**; regras de ciclo de vida mudam a classe ou apagam o objeto com o tempo ([classes do S3](s3-classes-de-armazenamento.md)).

## Opções principais

| Recurso | O que faz | Quando lembrar |
|---|---|---|
| Bloqueio de Acesso Público | Impede que o bucket fique público por engano | "Evitar exposição acidental" |
| Versionamento | Guarda versões anteriores de cada objeto; vem desligado | "Proteger contra exclusão ou sobrescrita acidental" |
| URL pré-assinada | Dá acesso temporário a um objeto privado | "Pai baixa o boletim por alguns minutos" |
| Replicação | Copia objetos para outro bucket, em outra Região ou na mesma | "Cópia em outra Região" |
| Object Lock | Impede apagar ou sobrescrever por um período (WORM) | "Exigência regulatória de retenção" |
| Site estático | Serve HTML, imagens e scripts que rodam no navegador | "Site sem servidor, só páginas estáticas" |

## Como é cobrado

Você paga pelo **armazenamento** (tamanho, tempo guardado e classe), pelas **requisições** e **recuperações** e pela **transferência de dados** para a internet. A entrada de dados vinda da internet não é cobrada, nem a transferência entre buckets ou para outros serviços da AWS na mesma Região, nem a saída para o CloudFront. A criptografia SSE-S3 não tem custo adicional.

## Não confundir com

| Serviço | Diferença para o S3 | Pista no enunciado |
|---|---|---|
| [Amazon EBS](ebs.md) | Disco em bloco de uma instância do EC2, numa zona de disponibilidade | "Disco da instância", "banco de dados no EC2" |
| [Amazon EFS](efs.md) | Pasta compartilhada (NFS) montada por várias instâncias Linux | "Várias instâncias lendo os mesmos arquivos" |
| [Amazon CloudFront](../redes/cloudfront.md) | Entrega o conteúdo do bucket com cache perto dos usuários | "Baixa latência para usuários no mundo todo" |
| [AWS Storage Gateway](storage-gateway.md) | Leva o S3 até o datacenter do cliente, com cache local | "Servidores locais", "pasta de rede local" |
