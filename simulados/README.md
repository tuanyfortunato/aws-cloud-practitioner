## Registro dos seus simulados

Registre aqui cada simulado realizado. Crie um arquivo por simulado usando o
[template](../templates/simulado.md), com o nome `AAAA-MM-DD-fonte.md`
(ex.: `2026-10-15-skillbuilder.md`).
