# Guia do Exame — AWS Certified Cloud Practitioner (CLF-C02)

> Confira sempre o [guia oficial do exame](https://aws.amazon.com/certification/certified-cloud-practitioner/) — valores e detalhes podem mudar.

## Formato

| Item | Detalhe |
|---|---|
| Código | CLF-C02 |
| Questões | 65 (50 pontuadas + 15 não pontuadas) |
| Tipos | Múltipla escolha (1 correta) e múltipla resposta (2+ corretas) |
| Duração | 90 minutos |
| Nota mínima | 700 de 1000 |
| Idiomas | Inclui português (Brasil) |
| Aplicação | Centro de testes Pearson VUE ou online (supervisionado) |
| Validade | 3 anos |

> Questões em branco contam como erradas — **nunca deixe nenhuma sem resposta**.

## Dicas para o dia da prova

- Leia a pergunta inteira antes das alternativas e procure a **palavra-chave** ("mais barato", "menor esforço operacional", "alta disponibilidade").
- Elimine as alternativas claramente erradas primeiro.
- Use o recurso de **marcar para revisão** e volte depois.
- Em questões de múltipla resposta, o enunciado diz quantas escolher.
- Ao final, revise as marcadas com o tempo restante.
